# Sparklets.IM Frontend

Vue 3 frontend for Sparklets.IM

## Setup

1. Install dependencies:
```bash
cd frontend
npm install
```

2. Run the development server:
```bash
npm run dev
```

The app will be available at http://localhost:18003

## Build

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

## Tech Stack

- Vue 3
- Vite
- Vue Router
- Pinia (state management)
- Axios (HTTP client)
